# Theorie der Finite-Elemente-Methode

Kursseite zum Modul *Theorie der FEM* (HTWK Leipzig, Prof. Dr.-Ing. Stephan Schönfelder).
Veröffentlicht unter <https://prof-schoenfelder-lab.github.io/Theorie-FEM/>.

- `vorlesung/` – Vorlesungen (Quarto, scrollbasiert)
- `beispiele/` – interaktive Beispiele (marimo, laufen im Browser)
- `mathematica/` – Übungsaufgaben als Mathematica-Dateien
- `grafiken/`, `werkzeuge/` – Grafiken und die Skripte, die sie erzeugen

Lokal bauen: `./bauen.sh vorschau` (http://localhost:8768).
Entwürfe, die noch nicht veröffentlicht werden, stehen in `entwuerfe.txt`.
